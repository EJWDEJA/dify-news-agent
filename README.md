# 🤖 客服03 - 自媒体爆款文案生成 Agent

一个基于 **Dify** 平台与 **DeepSeek-v4-flash** 模型构建的智能自媒体运营助手。它能够敏锐捕捉全网热点，并自动结合内置的排版规范知识库，一键输出适用于小红书、微信公众号等平台的高质量、高互动率自媒体文案。

## 🌟 核心功能

1. **实时联网搜索**：自动调用 DuckDuckGo 搜索引擎，抓取与主题相关的最新爆款观点、客观事实与核心数据，拒绝凭空捏造。
2. **知识库风格对齐**：自动检索《自媒体爆款排版与风格指南》，严格对齐排版结构、Emoji 密集度、语气与受众偏好。
3. **高转化结构输出**：产出的文案标配：吸睛标题 + 黄金前三句 + 模块化干货正文 + 引导评论的互动结尾。

## 🛠️ 技术栈与工具集成

- **核心大脑**：`DeepSeek-v4-flash` (通过 LangGenius 提供)
- **联网工具**：DuckDuckGo Search / DuckDuckGo Image / DuckDuckGo Translate
- **数据召回**：多路混合检索模型（向量检索 + 全文检索），Top K = 4

## 🚀 如何在你的 Dify 中复现此项目？

### 前提条件
- 拥有一个 [Dify.ai](https://dify.ai/) 账号（云端版或私有化部署版均可）。
- 准备好你的 DeepSeek API Key 并已在 Dify 的“模型供应商”中配置完成。

### 导入步骤
1. 下载本仓库中的 `app_config.yml` (或复制其代码)。
2. 登录 Dify 控制台，进入 **“工作室” (Studio)**。
3. 点击 **“创建应用”** 旁边的下拉箭头，选择 **“导入 DSL 文件” (Import DSL file)**。
4. 上传下载好的配置文件，即可一键克隆一模一样的 Agent。

### ⚠️ 注意事项
1. **知识库绑定**：导入应用后，你需要前往 Agent 配置页面的“知识库”模块，重新创建一个名为 `自媒体爆款排版与风格指南.docx` 的知识库，并与之关联，否则知识库对齐步骤可能会失效。
2. **工具授权**：初次导入后，确保 Dify 平台上的 DuckDuckGo 插件处于启用状态。

## 📋 编排规则详解 (System Prompt)

本 Agent 内部的核心运行铁律如下：
- **步骤一：全网搜索**：收到用户主题后，必须优先检索最新热点，至少参考 3 个搜索结果。
- **步骤二：知识库对齐**：生成最终文案前，强制调用知识库，规范段落与语气。
- **约束条件**：严禁无据造势，文案必须兼顾干货度与传播性，多用短句、空行和 Emoji。
